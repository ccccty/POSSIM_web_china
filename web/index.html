关于本平台

珠江口风暴潮淹没推演平台（POSSIM-Web）是 POSSIM 3.0（C#/.NET + Fortran 版）的浏览器演示移植：把逐像素风暴潮模型（Holland 梯度风 + 反气压增水 + 风增水 + 波增水 + 调合天文潮）挂到一套零构建的 Web 大屏上。

· 地形：SRTM 90 m 降采样为 3 角秒（约 103 m）等经纬网格，1188 × 864，范围 113.20–114.20°E / 22.20–23.00°N，行序自北向南。
· 天文潮：M2 / S2 / K1 / O1 四个分潮按 η = Σ A·cos(ω·h + φ) 叠加，h 为 2000-01-01T00:00Z 起的小时数。
· 台风：参数来自历史过程线（示意还原），前端可手动覆盖 Vmax / Pc / 移速 / 移向后重新推演。
· 后处理：淹没深度分级 0–0.33 / 0.33–0.5 / 0.5–1 / 1–2 / 2–3 / 3–5 / >5 m，并做 4 连通性过滤，丢弃不含海岸种子的孤立斑块。

· 实现：前端 HTML + CSS + 原生 JS（Leaflet 1.9.4 / ECharts 5.5.1 走 CDN），无构建工具；后端 Python 标准库 http.server + numpy/Pillow。

数据与成果仅用于技术演示，台风与灾情为历史/示意情景，不用于实际防汛调度与决策。
